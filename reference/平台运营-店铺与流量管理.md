# 平台运营篇：店铺与流量管理

> 本文档从「业务谈判-销售全流程」中分离，涵盖阿里巴巴国际站**平台运营**内容（店铺装修、商品发布、价格布局、流量推广、数据分析等）。适用于运营人员/老板，**非销售分内工作**。
>
> 分离原则：销售人员的核心工作是客户沟通与订单转化；店铺装修、P4P 推广、商品发布优化、实力标签管理等属于平台运营工作，不应由销售人员承担。销售人员请参考「业务谈判-销售全流程」。

## 1. 阿里平台线上表达（店铺装修与展示）

**核心理念**：国际站是电商属性，客户看不到你，只有通过线上表达才能传递价值。

> "纵使你线下的规模再大，客户进到你破破烂烂的线上店铺以后，他也不敢给你下大单。"

**阿里线上表达**：
- 顶展、金品（花钱的）
- 新等级、年限、验厂视频、VR showroom、装修、详情等（不花钱的）
- 证书展示技巧：每个证书下写三行字 - ①证书名称 ②编号 ③生效日期
- **顶展话术案例**："这个型号的产品，在阿里巴巴上我们销售遥遥领先，因为无论何时你搜索这个产品，我们永远在第一位"

### 实力标签扬长避短

- 路径：认证中心 → 实力标签 → 已选标签
- **核心原则：扬长避短**，只保留优势标签，撤下短板标签
- 反面案例（深圳贸易公司）：厂房面积67平米、注册才1年、员工只有2人（老板+媳妇）→ 全撤下
- 正面案例（徐州大厂）：员工3万多人，"客户一般只要上门就跑不掉了，开车子在厂里面转一圈要开15分钟"
- 大部分标签只需提交资料即可获得，不需上门验厂（如100%成品出厂检验标签，只需提供出厂检验记录表）
- 所有标签都参与AI搜索匹配

> **思维转变**：工厂老板不要只想着"怎么降低一毛钱成本"，要想着"怎么把订单搞下来"。贸易公司的优势在于专注搞订单，交付可以找工厂解决。

## 2. 商品发布与内容运营

### 主图视频规范（45秒结构）

- **必须真人出镜**（样品间/车间/任何地方都可，必须出镜）
- 中文拍摄 → 后台"视频银行 → AI视频创作"翻译（实测嘴型对得上）；英语不好也可中文拍摄+视频翻译
- 不需要专业拍摄，自然展示即可——"今天不管中国还是国外，都在流行不特别精致的有活着感的视频"
- 拿在手里讲或放桌上讲，**不要用转盘转产品**（5年前还有新颖，现在没人看）
- 剪映美颜：女生开100%，男生只能开30%（开100%爸都不认识）

**45秒结构**：
- 前15秒：商品卖点（卖点少的一带而过）
- 中间25秒：公司实力+服务能力
- 最后5秒：行动号召（"找到屏幕底部的向上按钮，立刻获取免费样品"）
- 禁忌：不要用一道光闪过+logo跳舞结尾

### 详情页"6张主图微详情"结构

在瀑布流推荐场域，客户滚动详情页时六张主图就构成"微详情"：
- 第1-3张：商品细节
- 第4-5张：公司实力和服务能力
- 第6张：行动号召（CTA）"快点点击下面的Contact Now按钮，获取XXX"

反面案例：6张图全是产品图，B端客户看不出实力。
正面案例（毛绒玩具）：1玩具+2工厂+3合作过的大客户+4 OEM/ODM能力+5 CTA。

## 3. 店铺价格布局与分析

### 价格布局（店铺层）

- 店铺布局**低中高全覆盖价位**——奔驰案例：A系列十多万到S系列一百多万全价格线，大采购商不会只采购单一SKU，会多价格段采购覆盖自己市场不同层次客户
- "百年豪华品牌都在做全价格带布局，只切单独价格段很难做大"
- **价格底线**：实际成交价不能低于页面价50%，否则订单权重被剔除（能收款但无运营帮助）
- **180天最低价规则**：页面价/折扣价/实际成交价三者取最低，**先降价再涨价会被平台限流**

### 价格分析工具用法

- 找竞争对手路径：数据参谋 → 流量参谋 → 流量承接及去向 → 流量去向 → 店铺名称（看最近30天跑去看同行的客户）
- Action Work 分析提示词："我是一家主要通过阿里巴巴国际站做外贸的汽配公司，帮我分析这个家伙的整体情况，仔细分析阿里巴巴国际站店铺"
- 也可直接做价格分析："请分析2025-2026年3M胶类产品在美国的平均采购价格区间，按低中高分类"

## 4. 流量与推广

### 自营销三件套（免费流量动作）

在付费推广同时做免费自营销：
1. **阿里卖家群发**（老客户TM群发邀约，销售侧使用方法详见「业务谈判-销售全流程」第6节）
2. **Tips 短视频**
3. **数字人直播**

### 买家分层与 P4P 溢价

平台买家分层：L1 → L2 → L3 → L4，等级越高价值越大。
- **L2 对商家最有帮助**，L3+ 转化率远高于普通买家
- 高质量买家标签来源：平台老客、回访买家、潜在交易买家、已成交买家

**L3+ 买家溢价**：虽然点击成本更高，但回报更高。实测：L3+ 商机转化率 16.42% vs 全站 6.51%。门槛=金品诚企可开启，比例按系统推荐 200%~300%。

### 借壳上新品（配件数据运营）

适用于高货值工程设备（如挖掘机）：
- 把易损件/保养件（密封圈、保险丝）拆分成独立产品ID，每次出货必送，写到订单里
- 积累一段时间后，这些配件ID上累计了高销量+好评+复购数据
- **关键操作**：上新设备时，直接修改这些配件ID的类目、标题、图片，**商品ID不变，销量/好评/复购数据全部保留**
- 配合广告投放+TM群发老客户，"三天到七天把它干到榜单上去"
